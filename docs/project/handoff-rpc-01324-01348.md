# RPC-01329–RPC-01353 Host coverage handoff

## Scope and status

The crateService routes in RPC-01329–RPC-01343 are implemented and registered through the production inventory RPC composition. The real Host socket regression is in `dotnet/tests/Eve.Host.Tests/CrateServiceHostWireTests.cs`; its test backend controls persistence state, while calls traverse Host registration. This work adds Host wire coverage for crimewatch RPC-01346–RPC-01348 and the existing neighboring crimewatch methods. RPC-01344 `ApplyTagsForSecStatus` remains missing; this batch is not complete until an authoritative exchange implementation, production Host wiring, persistence, notifications, and focused regressions are added.

Tag quantities are read at `eve/client/script/ui/station/securityOfficeSvc.py:28-36`; fee display is derived from the dogma attribute at `securityOfficeWindow.py:105-109`; tag counts are presented at `:198-207`. ## EveJS comparison

The v0.12.9 crate implementation is `server/src/services/campaign/crateService.js:542-704`; it resolves locations, opens and peeks inside crates, consumes loot and grants fitting/skill-bundle contents. eve.rs is `dotnet/src/Eve.Services.Core/CrateService.cs:64-243`, registered through `dotnet/src/Eve.Host/Rpc/InventoryRpc.cs` with its persistence backend. v0.12.9 crimewatch implements client state and security status at `server/src/services/security/crimewatchService.js:58-62,100-116`, and has no `ApplyTagsForSecStatus` implementation. No EveJS behavior is copied for that missing operation.

## Regression

`dotnet/tests/Eve.Host.Tests/CrateServiceHostWireTests.cs` sends crate RPCs through the actual Host and registered route, and checks reply shapes, invalid input, transport `machoVersion`, and item-change notification order. `CrimewatchHostWireTests.cs` sends bound calls through the actual Host socket. Its new test covers GetClientStates, security status, transaction rowset, safety, and duel method replies. The data source is constructed but never opened; no PostgreSQL was used. These are headless wire checks, not graphical-client verification.
