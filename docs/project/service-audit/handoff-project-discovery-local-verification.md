## Participation and bonus policy update

The default tutorial reward program remains disabled. `EVE_PROJECT_DISCOVERY_TUTORIAL_REWARD_POLICY=subcell-levels` and a positive integer `EVE_PROJECT_DISCOVERY_TUTORIAL_XP`, together with a configured training catalog and either disabled or Subcellular remote mode, opt into a local participation award for eight recorded level advances. This is not scientific correctness verification: the unmodified tutorial checks answers locally and does not submit them. Skip is ineligible, reset does not erase the one-time receipt, and the transaction persists the award in the character's Project Discovery XP owner. The configured XP is also returned by `get_tutorial_xp_reward`; ISK and items are not awarded by this policy, matching the Subcellular completion display. Actual Host/PostgreSQL test `Participation_policy_grants_xp_once_and_skip_is_not_eligible` passed with encoded task issuance, account isolation, restart, claim replay, reset and rank/XP readback; no skip.

`EVE_PROJECT_DISCOVERY_BONUS_POLICY=none` (default) disables bonuses. The `daily` policy requires positive `EVE_PROJECT_DISCOVERY_BONUS_DAILY_MAX`, positive fixed `EVE_PROJECT_DISCOVERY_BONUS_XP`, and `EVE_PROJECT_DISCOVERY_BONUS_RESET_UTC_HOUR` (0–23); these are operator rules, not CCP rules. Accepted non-training classifications atomically consume a daily slot and award fixed XP, independent of score. Skip, training, unknown delivery and replay do not consume a slot. The response reflects committed local reward receipts, not upstream reward claims.

The optional Subcellular catalog at `EVE_PROJECT_DISCOVERY_TRAINING_CATALOG` is a JSON object with integer `projectId`, nonempty `source` and `license`, and exactly 24 entries in `tasks`. Each entry has `taskNumber = projectId * 10000000 + rawId` for raw IDs 0–23 and a `task` containing `taskId`, absolute HTTP(S) `assets.url`, and a unique 1–5-element integer `solution` in the pinned 9–35 range. The Host returns its projectId from `get_project_id`; issued tasks are account- and catalog-revision-scoped, and each level requires the client-defined minimum issuance count before advance. The controlled catalog in tests is synthetic test data; no genuine catalog is bundled. A catalog is permitted only with disabled or explicitly configured Subcellular remote mode.

The separate `exoplanet-local-finish` tutorial policy requires operator-selected `EVE_PROJECT_DISCOVERY_TUTORIAL_CRATE_TYPE` (validated against the pinned SDE) and `EVE_PROJECT_DISCOVERY_TUTORIAL_WALLET_REF_TYPE`, and disabled or Exoplanet remote mode. An authenticated self-reported finish awards the client-displayed 900 XP, 250000 ISK and one specified item at the character's home-station hangar, atomically with a receipt. The client sends no authoritative answers or intermediate completion evidence; this policy is not correctness verification. Skip is ineligible; reset cannot erase the receipt; the same session/call replay returns its saved result. The displayed tutorial crate has no evidenced type ID, so there is no default.

Remote protocol profile is selected by `EVE_PROJECT_DISCOVERY_REMOTE_PROTOCOL=covid|exoplanet|subcellular`; the MMOS project code is separately configured and treated as opaque. Exoplanet/Subcellular task data and classification endpoints require an explicit real upstream; mock HTTP tests are not live evidence. No graphical client or live MMOS test was performed.
