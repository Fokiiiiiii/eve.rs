## Increments

1. **Foundation (inert, not bound in the host).** Site definitions as content (`anomaly` / `signature`, `site.{id}`) from the static site table (`Sites/Data/site-templates.json`, generated by `tools/dev/extract-site-templates.py`); `CosmicSiteDirector` (the recurring `site.spawn` job per system, the `content.{anomaly,signature}.{completed,expired}` respawn subscriber, and slots `system:{id}:slot:{n}`); `ContentCosmicSites` as the `ICosmicSiteSource` implementation (signatures with their code and level); and code / dungeon fields in scan rows. Tests: `CosmicSitesTests.cs`.
2. **Activation (built).** Host binds the director: `SpaceComposition` attaches it before `foundations.StartAsync`, a pilot entering a system gets its sites (`SystemEntered` -> `EnsureSitesAsync`), probe scans read `ContentCosmicSites`, the anomaly reader asks the director first, and `BeyonceService` warps to a scan result by code. The scan through the Beyonce rig with a content-backed source still needs a live walk.
3. **Clear and respawn (built, test).** A site cleared by NPC kills (`npc.killed { site, solarSystemId }`) and containers completes; the respawn subscriber replaces it in its slot elsewhere; restart preserves progress. The regression publishes kills from the test; production NPC integration is covered in increment 5.
4. **Probe results (built, tests).** Signature results follow wiki strengths 42, 72 and 104; the 100% coverage rule comes from the existing engine.
5. **NPC waves (built, tests).** `SiteNpcs` makes the active site wave in the system scene when a pilot is present and no NPC from that site remains. NPC kills carry the site id. System entry and each completed wave trigger a spawn. No new simulation message or protocol bump. A system with no pilots gets no site or wave.
6. **Containers (built).** Data and relic site containers (groups 306, 1207) are placed; analyzers and hacking persist failures, destroy containers after two failures, grant win loot and publish `site.container.cleared` when the last item leaves.
