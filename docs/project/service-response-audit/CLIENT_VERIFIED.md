## EveJS 261018.1 comparison

- EveJS Slash returns a command result string and flushes command session effects after the call: `src/server/src/services/admin/slashService.js:214-278`; its command table has no bare `/spawn` (`src/server/src/services/chat/chatCommands.js:409,1287`). The V24 client caller requires an item ID from that existing eve.rs command, so the client-driven typed result is documented in `docs/reference/compat/DEVIATIONS.md`.
- Interference state is a six-field state ObjectEx; all active system bands are a dict keyed by system ID: `src/server/src/services/map/solarsystemInterferenceMgrService.js:53-83`.
- Standing RPCs return rowsets/lists and cache compositions for five minutes: `src/server/src/services/character/standingMgrService.js:194-241`; transaction/composition values come from `src/server/src/services/character/standingRuntime.js:487-520,1035-1061`.
- Station replies match the consumed records, tuples and lists, including cached GetStation and alliance KeyVals: `src/server/src/services/station/stationService.js:68-215`.
- Character/corporation asset-safety replies are lists of wrap KeyVals: `src/server/src/services/structure/structureAssetSafetyService.js:185-209`.
