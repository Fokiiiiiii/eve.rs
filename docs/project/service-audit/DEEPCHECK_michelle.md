# michelle / beyonce deep check

対象は EVE V24.01 build 3396210 の `/home/user/eve-logic` 全体、Host の `beyonce`、EveJS 261018.1 の `src/server/src/services/ship/beyonceService.js`。EVE クライアントにリモート `michelle` サービスはない。`michelle.py:372-376` の `GetRemotePark()` が bound ballpark を返し、`eveMoniker.py:141-144` が `Moniker('beyonce', solarsystemID)` を作る。したがって調査対象はローカル client service `michelle` が呼ぶ `beyonce` の bound / unbound RPC である。`MachoNetService.cs:45` が `beyonce -> solarsystem2` を公開し、`AgentRpc.cs:110` が実 Host サービスを登録する。

## 集計

- `beyonce` の RPC 名で呼ばれるのは下表のもの。client は `machoVersion=1` を transport kwargs に付ける（`ServiceCallGPCS.py:221-225`）。本体 kwargs は主に `CmdWarpToStuff`, `CmdAlignTo`, bookmark RPC に渡す。
- Host で登録済み: moniker resolve/bind、bookmark 作成2件、diagnostic3件、state request、移動6件、`CmdAbandonLoot`、warp2件、stargate jump、fleet beacon travel7件、component dispatch。Host 登録位置は `BeyonceService.cs:93-758` と `BeyonceService.Components.cs:15`。
- client が呼ぶのに Host `beyonce` に未登録: fleet state/location、relativity、container expiry、siphon capacity、operation spawnpoint、goto point/bookmark、steer direction、fleet regroup/tag、corporate asset transfer、structure self-destruct開始/取消。これらの wire call は Host で到達不能で、dispatcher の method-not-found error が EveJS/client の method-specific error/behavior を置き換える。
- `CmdAbandonLoot` は当初 `entity` にだけ登録されていたため届かなかった。今回 bound `beyonce` へ同じ `ISpaceContainers` provider を配線し、この route gap を修正した。
- `CallComponentFromClient` の Host route は登録されているが、実処理は `linkWithShip.InitiateLink/InitiateLinkQuick` のみ。それ以外を常に `None` で返すため、下表に記載の client 操作を満たさない。
- Host に存在し Eve V24 client の呼び出しが見つからない `CmdDock` は監査対象外（EveJS/Host には実装あり）。

## EveJS 比較と重要な Host 欠落

EveJS 261018.1 の Beyonce handler は `CmdSteerDirection`, `CmdGotoPoint`, `CmdGotoBookmark`, `CmdFleetTagTarget`, `CmdAbandonLoot`, `CmdSelfDestructStructure`, `CmdAbortSelfDestructStructure`, `GetCapacityOfSiphon` を実装する。component dispatch は above 既存 component を runtime/provider に渡し、method-specific reply/error を返す。Host は上記のうち `CallComponentFromClient` の link 操作だけを持つ。 `GetOperationSpawnpointPosition` は EveJS KeeperService 側。fleet diagnostics と `CmdFleetRegroup` に EveJS handler は見つからず、regroup の期待動作は EVE University Fleet interface に従う。corp asset ownership transfer は EveJS 261018.1 に handler が見つからない。
