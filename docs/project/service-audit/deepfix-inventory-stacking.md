Updated 2026-11-02. Scope: station hangar and container moves, batch moves, StackAll, SplitStack, loot capacity, and the client-visible inventory notifications and errors.

## Defects and corrections

1. **Station drag/drop with the client’s explicit hangar flag returned None.** `MultiAdd` rejected every flag except ship holds and corporation divisions, even when its bound destination was the personal station hangar. The client then skipped its post-success event. The route now permits `ItemFlags.Hangar` only for `Kind.Hangar` (`dotnet/src/Eve.Services.Inventory/InvBrokerService.cs:1511-1514`). Its DB-backed RPC regression asserts the true response, persisted location/flag/quantity, and ordered `OnItemChange` packets (`InventoryRpcFixTests.cs:184-208)).
2. **Cargo containers could be placed inside other cargo containers.** The pinned SDE classifier checks container group and positive `capacity` (plus the named cargo-container type) (`dotnet/src/Eve.Ships/CharacterShips.Containers.cs:177-197)). A shared refusal now runs before the docked move mutation and before in-space ship-to-container mutation (`CharacterShips.Containers.cs:292-297,359-361)); docked `MultiAdd` preflights eligible source types before moving any item (`InvBrokerService.cs:1547-1562)). `ShipErrors.Of` returns EveJS’s `CustomNotify` and exact client text, “A cargo container cannot be placed inside another cargo container.” (`dotnet/src/Eve.Services.Ships/ShipErrors.cs:47-48)). Regression coverage proves no item or notification is committed for a rejected batch (`InventoryRpcFixTests.cs:211-236)), and covers docked and in-space direct moves (`ShipTests.cs:848+`, `CargoTests.cs:374+`).

Both behaviors match EveJS 261028.1: `invBrokerService.js:13375-13490` preflights batch transfer guards; `1381-1397` maps nesting to the same notification; `5769-5819` resolves an explicit hangar flag; and `itemStore.js:6655-6702` rejects cargo-container nesting. EVE University states containers cannot be placed inside other containers: [Containers](https://wiki.eveuniversity.org/Containers). Container classification and capacity values come from the pinned SDE-backed `DogmaStatic`, not packet snapshots.

StackAll, SplitStack, and capacity formulas had no new defect in the selected scenarios; their existing server behavior and tests were reviewed. The SplitStack difference from EveJS is already recorded at `docs/reference/compat/DEVIATIONS.md:17`: the current EveJS inventory broker lacks the ordinary handler, while V24.01 calls it and eve.rs implements the transactional source reduction plus same-location stack creation. EveJS’s contract-proxy stub is a separate path.
