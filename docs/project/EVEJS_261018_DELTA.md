# EveJS 261018.1 delta assessment

Date: 2026-10-19. Reference: extracted `/home/user/evejs-new` release 261018.1; old comparison tree `/home/user/evejs-v0.12.9` (0.12.9). The extracted trees are read-only behavior references. The release contains 153 added, 64 removed and 1,528 changed text files under `server/src`; config has five changed JSON files and `doc/` has one added and eight changed files. This is a large release, so this assessment classifies all owner-supplied release-note feature groups and the named held-data questions; it is not a method-by-method audit of every changed JS line. Content packs identify themselves as `evejs.content-pack.v1`, with manifest/payload and provenance/confidence fields. Where a source-build number is given, these assets were compiled from client build 3475087, not target V24.01 build 3396210.
