# RPC-01324–RPC-01348 Host coverage handoff

## Scope and status

This batch covers crateService rows RPC-01324–RPC-01343 and crimewatch rows RPC-01344–RPC-01348. The existing crateService implementation is registered in the production inventory RPC composition and delegates mutations to its persistence backend. This change adds a real Host socket regression covering its seven methods, malformed input, transport-added `machoVersion`, reply shapes and item-change notification order. The real Host wire regression for GetCharacterSecurityStatus is in `dotnet/tests/Eve.Host.Tests/CrimewatchHostWireTests.cs`; GetClientStates still needs Host wire coverage, and RPC-01344 still needs an authoritative security-tag exchange implementation and regression. Do not treat the batch as complete until those are finished and the Actions checks pass.

## Client evidence and behavior

- RPC-01324/01325 `ClaimFitting`: `eve/client/script/ui/crate/lootItem.py:103-105` calls it with the fitting item ID; the claim action consumes the result without interpreting a payload.
- RPC-01326/01327 `ClaimLoot`: `eve/client/script/ui/crate/lootItem.py:52-56` passes item ID, destination ID and flag; the UI uses the claim as an action and refreshes inventory from notifications.
- RPC-01328/01329 and RPC-01330/01331 `ClaimLootFromCrateStack`: `eve/client/script/ui/crate/controller.py:108-132` and `:290-318` destructure the opened/remaining counts, report the multi-open result and decrement the visible stack.
- RPC-01334–01337 `GetCrateLocation` and RPC-01338–01341 `OpenCrate`: `eve/client/script/ui/crate/controller.py:88-106` and `:265-288` get the destination before opening and pass the loot into the UI. Inventory-menu entry points are `eve/client/script/ui/shared/item.py:843-844`, `eve/client/script/ui/services/menusvc.py:385-386`, and the menu wrapper at `menusvc.py:3522-3523` -> `menuSvcExtras/menuFunctions.py:508`.
- RPC-01332/01333 `ClaimSkillBundle`: `eve/client/script/ui/crate/lootItem.py:91-93` claims a skill bundle as an action.
- RPC-01342/01343 `PeekInsideFixedCrate`: `eve/client/script/ui/crate/controller.py:364-372` consumes rows as type ID, quantity and custom information.
- RPC-01344 `ApplyTagsForSecStatus`: `eve/client/script/ui/station/securityOfficeWindow.py:123-129` submits target and displayed current status, then refreshes in a finally path. Tag inventory counts are in `eve/client/script/ui/station/securityOfficeSvc.py:28-36`; fee display comes from the SDE/dogma fee attribute in `securityOfficeWindow.py:105-109`; requested counts are built at `:198-207`. The Security Office consumes `OnSecurityStatusUpdate` at `:130-133`. Eve University’s [Security tags](https://wiki.eveuniversity.org/Security_tags) page documents the four tag ranges, +0.5 status per tag, tag use only at non-positive status, possible final overshoot above zero, office restriction and ISK cost. EveJS v0.12.9 has no `ApplyTagsForSecStatus` implementation; behavior must follow those mechanics and the observed client contract.
- RPC-01345 `GetCharacterSecurityStatus`: `eve/client/script/ui/services/crimewatchSvc.py:594-596` calls it; consumers include `eve/client/script/ui/shared/neocom/corporation/corp_dlg_edit_member.py:146`, `eve/client/script/ui/shared/info/characterInfoWindow.py:65`, `eve/client/script/ui/shared/info/infoContentBase.py:413`, and the dogma callers `eve/client/script/dogma/clientDogmaLocation.py:747-750` / `eve/common/script/dogma/baseDogmaLocation.py:1937-1942`.
- RPC-01346–01348 `GetClientStates`: all callers are in `eve/client/script/ui/services/crimewatchSvc.py:87-123`. The client unpacks five timer pairs, engagements, criminal/suspect sets and safety; it uses these to update engagements, timers, flags and safety on subscription/session changes.

## EveJS comparison

The matching v0.12.9 crate implementation is `server/src/services/campaign/crateService.js:542-704`; it resolves crate location, opens/peeks, consumes crate loot and grants/claims fitting and skill-bundle contents. The existing eve.rs implementation is `dotnet/src/Eve.Services.Core/CrateService.cs:64-243`, registered through `dotnet/src/Eve.Host/Rpc/InventoryRpc.cs` with `PersistenceCrateServiceBackend`. Crimewatch reference behavior is in `server/src/services/security/crimewatchService.js:58-62,100-116` for `GetClientStates` and security status. It does not define `ApplyTagsForSecStatus`.

## Regression

This is a headless wire regression, not graphical-client verification. Run it on Actions with the focused Host test filter after committing.
