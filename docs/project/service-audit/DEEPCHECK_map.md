# Deep check: Host `map` service (2026-10-27)

## Scope and conclusions

A whole-tree search in `/home/user/eve-logic` for `RemoteSvc('map').<method>` found exactly the 22 unique RPC methods below. The direct callers listed in the table cover every match. The related occurrences of `sm.GetService('map')` are client-local static-map operations; they do not call Host. A whole-tree search for map bound-object/moniker patterns found no additional map RPC endpoints.

Host registers the service from `dotnet/src/Eve.Host/Rpc/DungeonRpc.cs:41-53`: `MapAccessGuardService` wraps `IncursionAnomalyService("map", ...)`, whose fallback is the registered `MapService`. The incursion service owns `GetIncursionGlobalReport` and `GetSystemsInIncursions` (`IncursionAnomalyService.cs:69-85)); the other 20 methods are advertised with `[Method]` on `MapService` (`StationService.cs:300-411,470`). Calls to other methods fall through to `MapService` and its production read hook. The wire tests use the Host socket/packet dispatcher and the actual service classes.

Valid client method arguments are positional: `GetHistory(statID, hours)`; `GetDeadspaceComplexMap(languageID)`; `GetDeadspaceAgentsMap(languageID)`; `GetFacWarZoneInfo(factionID)`; `GetCurrentSovData(locationID)`; and the two industry methods take `activityID`. All other calls below have no RPC arguments. A whole-client search found no keyworded method arguments; `machoVersion` is transport kwargs. Host dispatch preserves that kwargs shape, and the Host wire tests send it. The map service methods take `ServiceCall`, so transport kwargs do not get mistaken for method arguments. The shared ID readers accept both `PyInt` and `PyLong`; the focused wire test exercises both on history and faction-war arguments. It also exercises an omitted history argument and a None deadspace language value.

The only method-level client-visible error path established by the client and EveJS is the map access guard: in Abyssal Deadspace it returns the `CustomInfo` UserError with `info = "The map does not work inside Abyssal Deadspace."` (EveJS `src/server/src/services/map/mapService.js:221-287`; Host `MapTelemetryComposition.cs:103-114`). The real Host wire test checks the `ErrorResponse`, error name, info key and message. No endpoint-specific exception handling was found at the callers below; infrastructure/provider failures are not converted into fake data or success. Each RPC is read-only. No map RPC sends a notification or mutates state. `GetHistory` uses the EveJS one-minute method-result cache shape; the faction-warfare UI invalidates its cached zone data after its own upgrade action (`facWarSvc.py:69-75,150`; `infrastructureHub.py:168`).
