## Defects fixed

1. The generic `CmdDock` path previously treated any non-station ID as an ordinary simulator dock, bypassing structure ACL. It now routes known structures through the same Host access check; the V24 client uses the dedicated structure RPC (`SpaceSessions.Movement.cs:20-56`, `SpaceSessions.Structures.cs:10-65`, `StructureComposition.cs:336-339`). A registered-Host regression covers denied and allowed generic calls (`StructureDockingTests.cs:68-87`).
2. The simulator previously finalized and removed the pilot after four seconds, before Host could recheck mutable timers or ACL. It now emits readiness command 255, keeps the pilot pending, and accepts Host's station-scoped decision command 254; denial clears pending docking and restores ball mass, while approval alone emits `Docked` (`crates/eve-space/src/scene/mod.rs:80-85,110-111`, `scene/session.rs:746-765`, `scene/docking.rs:198-252`, `sim/dispatch.rs:5-15`). The Host readiness match is excluded from the earlier generic `SimAccepted` handler so it reaches final authorization (`dotnet/src/Eve.Services.Space/SpaceSessions.cs:868-898`); final checks use current module restrictions, movement/Crimewatch policy and structure ACL (`SpaceSessions.Movement.cs:550-587`). Pilot teardown now also occurs after a decision command reports `Docked` (`crates/eve-space/src/sim/spawn.rs:813-820`, `sim/dispatch.rs:996-1010`).
3. When the delayed final check denied docking, the client had received `OnDockingAccepted` but no terminal notification; its tactical docking state could therefore remain set. EveJS also only clears pending state and logs the delayed failure (`tick.js:2403-2411`), but the complete V24 consumer trace shows `OnDockingFinished` is the only event that clears that state. Host now sends that terminal event on a denied final decision while leaving the pilot and session in space (`SpaceSessions.Movement.cs:550-591`). It does not send a location/session transition. Registered-Host tests cover revoked structure access and a weapons timer that starts during the delay (`StructureDockingTests.cs:91-123`, `SpaceServiceTests.cs:2003-2022`).

## Successful completion order

After simulator approval, Host persists the ship and condition through `Ships.DockAsync`, removes the pilot, sends `OnInvulnCancelled`, releases bound objects, sends `OnItemsChanged`, applies the station or structure session tuple, then sends `OnDockingFinished` and invokes `DockedLocationChanged` (`SpaceSessions.Movement.cs:599-650`). Station and structure tests assert the wire notification/session ordering; no successful-path order was changed. Station docking sets `stationid/locationid` and clears `solarsystemid`; structure docking sets `structureid/locationid/solarsystemid` and clears `stationid`, matching GameUI's view transition consumers above.
