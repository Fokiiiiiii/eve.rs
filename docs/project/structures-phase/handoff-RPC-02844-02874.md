# RPC-02841–02871 Host coverage handoff (2026-10-25)

## Resolution status

The service methods for Deliver, deployment, structure directory reads/writes, and structure guests are implemented and registered in the Host composition. A real Host packet test now covers those routes, wire replies, and transport-added `machoVersion`. Their persistent behavior is also covered by existing Host composition/backend tests. The one remaining server-side gap in this batch is `structureJumpBridgeMgr.CmdJumpThroughStructureStargate`: its route is advertised but production Host composition supplies no travel callback, so it returns a refusal instead of completing a bridge jump.

RPC-02861 and RPC-02868 are client-local operations, not server RPCs: `clear_memoized` is the memoization wrapper on the map service (client `eve/client/script/ui/shared/maps/mapSvc.py:57-59`), and `pop(characterID, None)` mutates the local guests dictionary (client `eve/client/script/ui/services/structure/structureGuests.py:36-42`). They should not be registered on Host.
