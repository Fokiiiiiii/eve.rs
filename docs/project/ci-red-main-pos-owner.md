# Main CI red gate: POS unanchor custody

## CI history

CI run 1672 (`a96ec732`, run 42749603517, attempt 2) repeated the failure at `test_a_corporation_unanchors_and_scoops_its_control_tower:702`: the online tower's `UnanchorStructure` refusal said that the tower was not visible in the scene. This was a server defect, not a timing flake. Main commit `921459046` fixed the cause by resolving ball-backed deployed objects in the simulation's `PositionOf` query (`crates/eve-space/src/scene/movement.rs:118-141`).

The following main CI run 1673 (`921459046`, run 42752793932) got past that step and failed at `tools/headless-client/tests/test_structures.py:724`. The row was `98000004|30000903|0|evejs:structure-unanchor:hull:1990000372`: `98000004` is the corporation and `140000083` is the pilot. The test expected the pilot to own the hull before it was scooped.

The client `IsStructure` predicate accepts category 65 only (`eve/common/script/sys/idCheckers.py:420-426`), so a control tower follows the `LaunchForCorp`/`Drop` branch. The headless regression sends the same `ship.Drop` and `ship.Scoop` RPCs and directly invokes bound `posMgr.UnanchorStructure` for the middle transition. Existing compatibility record ST-23 says this RPC takes the tower item id (`docs/reference/compat/DEVIATIONS.md:4562`); the V24 source menu itself reaches dogma activation, and the graphical effect transition has not been verified.

In the specified EveJS checkout (`/home/user/evejs-261108.1`), `Handle_Drop` passes the optional behalf owner to `launchOrbitalsFromShip` (`server/src/services/ship/shipService.js:1614-1626`). Control-tower unanchor reconciliation updates `spaceState` while spreading the existing item, so inventory ownership is retained (`server/src/services/ship/controlTowerRuntime.js:1172-1180,1350-1369`). The Scoop mutation assigns the pilot as owner and places the hull in the current ship (`server/src/services/ship/cargoContainerRuntime.js:2117-2149`).

The corrected regression asserts corporation ownership while the unanchored hull remains in space. It retains the exact assertion that the pilot owns the hull in ship cargo after Scoop.
