## EveJS comparison and Host behavior

- EveJS `server/src/_secondary/express/gatewayServices/campaignGatewayService.js:3-8,56-75` replies with a typed empty campaign list; executing its runtime returned status 200, `GetAllResponse`, and a zero-byte payload. The Host now does the same.
- EveJS `dailyGoalsGatewayService.js:314-330` returns earned, unclaimed monthly milestone IDs. Host's `DailyGoalRecorder.cs:9-17,25-39,49-80` records only daily ore-mining and salvage goals, not monthly milestone claims, so it returns an empty typed page rather than inventing IDs.
- EveJS `structurePaintworkGatewayService.js:972-993` builds paintworks from authoritative per-system state. Host has no structure-paintwork state/provider, so it returns an empty typed list for the data Host owns.
- EveJS `evermarksGatewayService.js:244-254` reads persisted ship-logo entitlements. Host has no ship-logo entitlement grant/store path, so it returns an empty typed list for Host-owned state.
- EveJS `tools/DatabaseCreator/database-creator.js:1309-1327` records that it found no public SDE map-tag source and bootstraps empty regions, constellations, and systems. `mapTagsAuthority.js:18-31,329-356` emits a versioned FlatBuffer and CRC; `mapTagsGatewayService.js:141-180` returns its checkpoint. Executing the reference against that empty seed produced 44 bytes, CRC `2739352333`, with three empty vectors. Host now builds that FlatBuffer at runtime, reads the build tag from the loaded SDE, returns the matching checkpoint, and serves the asset at `/elysian-eve/map-tags/latest.maptags`.

The Host gateway tests use `CharacterHostRig` (real `HostComposition`, real gateway registration and HTTP/2 `Requests/Send`), not a handler-only test. They assert response status/type/payload, character and user-token refusals, checkpoint fields, and an HTTPS HTTP/2 asset download whose FlatBuffer vectors and CRC are checked. The checkpoint URL follows EveJS's HTTPS port-443 contract. The local integration test exercises the exact checkpoint URL through an ephemeral-port TLS test connection; no graphical V24 client was run, and the capture's gateway address is unknown. A deployment must make the hostname in the checkpoint reachable on HTTPS port 443, for example through its public TLS routing.
