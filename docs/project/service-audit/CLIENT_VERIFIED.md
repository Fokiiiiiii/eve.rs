- eve.rs public-info reply fields and types are asserted through the Host route. `GetPublicInfo3` uses a one-element PyList rather than EveJS's CRowset; the client callsites in this batch index row zero and read its named fields, which this reply supports.
- The prior Host test for asset item lists asserted a PyList containing a tuple, which did not demonstrate the named-field access used by the client. The added Host test supplies and asserts named item records for `List`, `ListStationItems`, and `ListIncludingContainers`.
- The recent-kill successful page is tested at the service layer, including paging and both consumer fields, but the Host wire test only exercises the unbound None branch. That leaves valid Host transport shape without a focused assertion.
