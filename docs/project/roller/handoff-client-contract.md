## Abandoned drone scoop differential follow-up (2026-10-24)

V24 `ship.ScoopDrone(objectIDs)` sends a list of drone item IDs. EveJS 261018.1 allows a pilot to scoop an abandoned, non-fighter drone with no controller within 2,500 m, provided the active ship has bay capacity; capture transfers item ownership to the scooper. EVE University describes abandoned drones as recoverable by any pilot inside scoop range ([Drones](https://wiki.eveuniversity.org/Drones)). eve.rs now registers the Scoop command end to end, leaves active or out-of-range drones in space, transfers a valid abandoned drone into the scooper's bay, and sends the persisted item change before the Destiny removal reaches the client. The range refusal matches EveJS's per-item `CustomNotify` text.
